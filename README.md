2. Project Idea & Objective
Project idea
Build a compact, reusable visual campaign system for KARKABA that uses AI-assisted research and creative development to define a clear visual direction, logo direction, color palette, typography, prompt library, 3–5 campaign visuals, before/after rationale, and reusable Canva/Figma templates.
انشاء نظام بصري مختصر وقابل لإعادة الاستخدام لعلامة كَرَكِبَة، بالاعتماد على البحث والتطوير الإبداعي بمساعدة الذكاء الاصطناعي لتحديد التوجه البصري، واتجاه الشعار، ولوحة الألوان، والخطوط، ومكتبة الأوامر النصية، وإنتاج ٣ إلى ٥ تصميمات للحملة، مع توضيح قبل/بعد وقوالب قابلة لإعادة الاستخدام.
Business / marketing problem
A new brand can appear inconsistent across posts and ads, making it harder for Egyptian families to recognize the offer and understand the value of giving unwanted household items a second life. Creating campaign assets manually can also take time and make it difficult to test multiple creative directions.
